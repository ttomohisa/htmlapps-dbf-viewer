使い方と注意事項

基本操作

  1. DBFファイルを選択またはドロップします。DBT / FPTがある場合は一緒に追加できます。
  2. ファイル情報とフィールド構成を確認し、データをページ単位で移動します。
  3. 文字化けする場合はファイル情報の文字コードを変更します。セルをクリックすると完全な値を確認できます。「前のレコード」「次のレコード」で同じフィールドを現在ページの表示順に確認できます。削除済みの表示設定に従い、ページの端で止まります。
  4. 必要なページを表示した状態で、現在ページをCSVとしてコピーまたは保存できます。

プライバシー

DBF / DBT / FPTはブラウザー内だけで読み取ります。このアプリから外部サーバーへ送信しません。

注意事項

  • 閲覧専用です。元のDBFやメモファイルを書き換えません。
  • CSV出力は読み込みが完了した現在ページが対象です。処理中や読み込みエラー時は利用できません。出力開始時の列・行・文字コード・メモ・ファイル名を保持します。タブやページを切り替えても開始済みの出力はその内容で完了します。元のタブを閉じるか同じファイルで新しい出力を開始すると、ブラウザーに渡す前の未完了の出力を中止します。
  • メモフィールドの内容には同名のDBT / FPTが必要な場合があります。メモファイルがなくてもDBF本体は確認できます。
  • DBFには複数の方言があります。未知のフィールド型や特殊なメモ形式は完全には表示できない場合があります。
  • NDX / MDX / CDXなどのインデックスファイルは使用しません。

配布用HTMLは実行時の外部通信を必要とせず、ローカルファイルとして直接開けます。
